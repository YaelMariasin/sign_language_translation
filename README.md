# Translating Israeli Sign Language to Hebrew Text

![Project Poster](./08c9c0c7-eba9-411c-8d08-39bf7f0b35e1.png)

This project focuses on translating **Israeli Sign Language (ISL)** from video input into **written Hebrew text**.

The system analyzes sign language videos, identifies meaningful gestures, and converts them into Hebrew words and sentences. The goal is to improve **accessibility and communication** for deaf and hard-of-hearing individuals in Hebrew-speaking environments.

This work was developed as a **capstone project** at Ben-Gurion University of the Negev and demonstrates the potential of combining computer vision and machine learning for sign-to-text translation.
