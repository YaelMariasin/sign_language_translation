# Translating Israeli Sign Language to Hebrew Text

This project explores the automatic translation of **Israeli Sign Language (ISL)** from video input into **written Hebrew text**.

The system analyzes sign language videos, identifies gestures and motion patterns, and converts them into meaningful Hebrew words and sentences. The goal is to improve **accessibility and communication** for deaf and hard-of-hearing individuals in Hebrew-speaking environments.

This project was developed as a **capstone project** at Ben-Gurion University of the Negev.
